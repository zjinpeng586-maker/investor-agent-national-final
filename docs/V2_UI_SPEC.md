# 财报智问 V2.0 UI 规范

> 历史版本资料：以下设计、实现范围及验收数字记录当时版本，不代表本次统一资料库修订的运行行为或测试结果。现行资料库、权限、迁移及披露流程见 [统一资料库与公开披露说明](统一资料库与公开披露说明.md)。

## 1. 总体方向

UI 参考团队 Version1 Demo 的信息架构与视觉克制原则，但正式版必须接入 V1.0 的真实业务能力，不得停留在静态样例。

目标观感：
- 金融研究工作台
- 清晰、专业、克制
- 以“问数”而非 Dashboard 为中心
- 评委第一次打开即可理解产品用途

## 2. 页面骨架

### 左侧固定导航
从上到下：

- 产品标识：财报智问
- 新建会话
- 财报问数
- 企业分析
- 研究资料库
- 数据中心
- 评测中心
- 最近会话
- 游客 / 账号入口

不再把模型配置、上传区、投资者画像长期堆在左侧。

### 顶部区域
仅保留：
- 当前页面名称
- 当前企业 / 报告期间等轻量上下文
- 必要的系统状态

不要全局固定展示企业 KPI、风险卡片和投资建议。

## 3. 财报问数首页

首页首屏：

- 文案：今天想分析哪家公司 / 想了解什么财务问题
- 3–4 个推荐问题卡片
- 大自然语言输入框
- 开始分析按钮

推荐问题优先选择比赛演示可稳定完成的场景：
- 某公司近三年营收变化
- 某公司净利润变化
- 两家公司核心指标对比
- 结合研报解释某项财务变化

企业与报告期间筛选可以保留，但它们是“当前理解条件”，不要求用户必须先选择。

## 4. 问数结果区

一轮结果建议保持在一个主卡片中。

优先顺序：

1. 结论摘要
2. 图表 / 数据 / 依据 三个视图
3. 当前企业、年份、指标口径
4. 报告预览 / 企业分析入口
5. 查询过程折叠区
6. 推荐追问

查询过程只展示对评委有价值的步骤，例如：
- 已识别公司与期间
- 已生成查询
- 已校验结果
- 已检索研究资料
- 已核对来源

不展示冗长内部日志。

## 5. 企业分析

一个页面承接 V1.0 企业分析能力。

建议包含：
- 企业基本信息
- 核心财务指标
- 趋势图
- 风险预警
- 同行业 / 指定企业对比
- 分析摘要
- 报告生成
- 继续问数

避免再把“总览 / 图表 / 对比 / 风险”拆成一级导航。

## 6. 研究资料库

展示：
- 文档名称
- 类型：年报 / 研报 / 行业 / 宏观
- 公司 / 行业
- 报告日期
- 来源
- 阅读入口

原文阅读中应能看到：
- 来源文件
- 页码
- 关键段落
- 被哪些回答 / 分析引用

## 7. 数据中心

推荐流程：

**01 接入 → 02 解析 → 03 复核 → 04 入库 → 05 来源追踪**

统一承接：
- 交易所公开披露
- CSV / Excel / PDF
- 在线 PDF
- 解析结果
- 异常提示
- 人工复核
- 数据来源

## 8. 评测中心

展示真实测试结果，不得用静态虚构百分比。

维度至少考虑：
- 查询准确性
- 查询结果正确性
- 多轮上下文
- 澄清能力
- 纠错成功情况
- 响应效率

每个指标允许进入：
- 测试题
- 标准答案
- 实际结果
- 错误案例

## 9. 视觉规则

- 允许使用深海军蓝侧栏 + 浅色工作区。
- 蓝色作为主要强调色。
- 星月元素只能做非常弱的品牌装饰。
- 不要过度渐变、发光或大面积动画。
- 常规动效约 200–400ms，避免 1.5–2 秒长动画。
- 首页可以留白，但不能空到像未完成页面。
- 优先桌面比赛演示，同时保证基本小屏适配。

## 10. 登录

比赛演示不出现强制登录页。

默认直接进入游客空间。
如后续增加账号，登录必须是可选入口，不能阻断评委演示。
