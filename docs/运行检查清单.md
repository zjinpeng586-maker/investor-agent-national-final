# 运行检查清单

比赛展示前依次检查：

1. 默认进入“财报问数”，五个一级页面均可打开。
2. 基础问数返回 SQL 成功状态和正确数值。
3. 连续追问能继承企业、年份和指标，新建会话会清空上下文。
4. 切换企业或指标后，Header、当前理解和实际查询一致。
5. 双企业对比的图表和数据均包含两家公司 SQL 记录。
6. 查询过程显示 SQL、参数、安全校验、执行状态和有效任务意图。
7. 已接入真实 PDF 时，RAG 引用显示真实文件、报告年份、PDF 页码和原文片段。
8. 企业分析可渲染指标、趋势、风险、企业对比并生成 PDF 报告。
9. 数据中心存在 CSV/Excel/PDF 上传、公开披露入口和来源追踪。
10. 评测中心初始无虚构百分比；运行后显示真实样本、Case 明细和 JSON 下载。
11. 本地模式不依赖 API；云端增强仅在主动选择并填写会话级 API Key 后使用。
12. Streamlit health 返回 `ok`，根页面返回 HTTP 200。
