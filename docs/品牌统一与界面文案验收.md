## 正式文案与真实状态

- 三个数据页签统一为“本地文件接入”“公开披露接入”“数据资产与来源”。
- 操作依次为“检索公开披露”“下载并解析”“数据复核”“确认入库”，检索完成和解析完成不代表入库。
- 入库成功分别展示真实新增数量、更新数量；仅文档标为“待补充指标”，不进入企业分析选择器。
- 数据库未提交、已提交但核验失败、无更新、仅保存文档独立显示，不将回查失败误说成未写入。
- 历史会话、无文件、无指标和无来源采用明确空状态；保持原有数据库查询、缺失条件拦截和只读部署控制。
- 浏览器复核发现隐藏后重新出现的企业选择框会回到首项；每次注册控件前明确同步当前企业和对比企业，保证前端收到恢复值。新增控件协议断言与真实浏览器跨页核验，报告下载企业必须等于当前选择。
- 来源、归因和查询诊断显示前移除本地绝对路径与 Python 堆栈，保留具体问题和操作提示；原文件仍可下载、定位页码。
