# Version1 星月界面版交付记录

日期：2026-09-24

## 本次改动

1. 按提供的 HTML 统一深蓝侧栏、浅色工作区、顶部上下文栏、推荐问题卡片、输入区和星月装饰；保留五个业务页面。
2. 推荐问题直接调用现有问答引擎；连续追问、澄清、SQL 校验、图表、数据与证据继续使用原实现。
3. 补齐新建与恢复会话；最近 10 个会话可恢复问答、企业、年份与上下文。
4. 问数结果新增实际可用的企业分析跳转、报告生成与详情收起；保留企业分析的报告与云端增强入口。
5. 修复研究资料库含特殊字符搜索、跨页面导航状态、SQL 执行参数表混合类型显示和增强报告刷新后内容丢失。
6. 手机默认收起导航，增强展开/收起按钮对比，修正侧栏底部裁切；浏览器深色模式下也保持浅色工作区。
7. 固定 Streamlit 1.64.0；Windows 启动脚本补目录定位与依赖安装失败处理。

`core/` 下 16 个 Python 业务文件与原版逐文件 SHA256 一致；数据库结构、解析、检索、SQL、风险计算和报告引擎均未重写。

## 验证结果

测试环境：Windows、Python 3.11、Streamlit 1.64.0、Chrome。

- 原项目基线：50 项测试通过。
- 新版干净副本完整回归：**63 项通过，53.67 秒**。
- 通过真实界面运行内置本地业务评测：**29 / 29**，已实际下载 JSON。
- 浏览器实测：自然语言问数、SQL 查询过程、两年两指标图表、历史恢复与连续追问、企业分析、资料搜索、CSV 上传入库与来源追踪。
- 实际下载问数生成的 PDF，并校验文件签名；上传验收数据不进入正式压缩包。
- 1440×1000 桌面、390×844 手机视觉检查：侧栏完整、移动导航可打开和关闭、输入可达、无页面横向溢出。
- 深色浏览器偏好下页面仍保持指定浅色主题；浏览器未捕获页面脚本错误。
- 云端报告增强使用模拟服务验证：增强文稿在两次页面重执行后仍用于 TXT/PDF，未重复调用服务；条件改变时旧缓存失效。
