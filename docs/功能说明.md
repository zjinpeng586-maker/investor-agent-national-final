# 功能说明

本系统采用“可信数据层 + 分析引擎 + 专业分析模块”的设计。核心财务指标来自本地结构化数据库、用户导入表格或公开披露资料；分析引擎负责问题理解、风险提示、企业对比和报告生成。

## 主要页面

- 公开披露检索：支持上交所、深交所公开披露文件检索与公开 PDF 接入。
- 企业总览：展示最新年度核心指标、综合评分和投资者参考结论。
- 企业对比：对比两家企业的评分、核心指标和能力雷达图。
- 图表分析：提供折线图、柱形图、饼图、雷达图。
- 智能问答：支持财务查询、趋势分析、风险识别、指标解释和企业对比。
- 分析报告：生成 7 页图文 PDF 报告。
- 数据与来源：展示企业数据、上传文件和公开来源记录。
