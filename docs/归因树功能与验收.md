## 怎么用

在“财报问数”输入 **比亚迪2024年净利润为什么变化？**，回答摘要下面自动展开“数因融合财务归因”。上方是归母净利润变化，下方分别为营业收入、毛利率和经营现金流。

点击“查看数据与报告依据”查看每个指标对应的文件、原始单位、单元格/页码与导入版本；符合条件的原因类报告引用可打开原文页或下载原文件。点击“归因查询与证据核验”查看实际只读查询、尝试次数、耗时、证据检查与拒绝原因。

**以下为基于财务指标变化与报告证据形成的归因线索，用于辅助分析，不代表严格因果贡献率。** 没有百分比分摊、因果概率，也不凭指标相关变化捏造业务原因。

## 数据与规则

| 项目 | 实现 |
| --- | --- |
| 触发 | 复用原解析与规划：hybrid、包含净利润、原因类语义、单企业。普通“净利润是多少”不生成树；多企业仍正常回答并明确跳过单企业归因。 |
| 查询范围 | 一个目标年→独立查询目标年和上一年；两个连续年份→比较这两年。多于两年或不连续年份→提示明确目标年，不随意截取两端。 |
| 未指定年份 | 通过只读 SQL 找到净利润可用的最新连续两个年度，明确显示采用的年度；不存在连续两年则提示数据不足。 |
| 根节点 | 变化额=本年−上年；变动率=(本年−上年)/abs(上年)×100%。零基数不计算比例；负基数明确标为以上年绝对值为基数。 |
| 收入线索 | 方向来自营业收入变化，只称收入端正向/压力线索，不计算其对利润的贡献金额或比例。 |
| 盈利能力线索 | 毛利率以%展示，差值以“个百分点”展示，不混用同比增长率。 |
| 现金流角色 | 始终是经营质量辅助线索；可观察与利润同向或不同步，不能作为净利润变化的直接原因。 |
| 缺失数据 | 根指标缺两年可校验数据→归因不足；可选指标缺失→只将该节点标为不足。先组合查询，必要时各指标独立安全查询，不用零填缺失。 |
| 证据 | 复用现有严格检索，限定同企业和目标年度。额外检查该指标同句原因、显式年份/期间、变化方向及否定表述；文件或页码缺失、相反方向、跨年或半年季度证据均不用于年度解释。 |
| 状态 | quantitative_and_document=量化+同年报告；quantitative_only=只有数值变化；insufficient=缺指标。没有证据时显示“当前仅形成量化归因线索，未检索到足够的同年度报告解释证据。” |
| 来源快照 | 仅在指标来源记录的值与 SQL 数值相同时关联该来源；行级历史记录不冒充某指标的独立证据。结果随会话快照保存，重跑或更新数据库不改写旧树。 |
| 云端与异常 | 模型不参与构造树的数值或节点。构建异常仅使归因组件降级，保留原问答，并记录实际失败。 |

组合/单指标查询最多5次，未指定年份再增加1次年度查找；每次沿用原 SQL 引擎最多2次尝试。每个有量化数据的节点最多检索3个候选结果、保留2条通过检查的引用，不新增模型调用。
