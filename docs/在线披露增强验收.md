# 在线披露与离线问答增强验收

验收日期：2026 年 9 月 25 日。本版在归因树封板基线之后恢复公共网页的完整资料接入链路，不修改数据库指标定义或旧作品分支。

## 实现范围

- public：每个 Streamlit 浏览器会话使用服务端随机标识选择独立 SQLite、附件和检索索引。下载和上传均先预览，确认后真实写入当前库，问数、企业分析和归因树读取同一库。不同访客不能通过界面选择他人会话。
- local：沿用本地持久化统一资料库，现有备份和恢复流程不变。
- readonly：保留显式只读访问；局域网只读脚本采用此模式。
- evaluation：仅内部测试使用，与业务资料库隔离。

公共会话不迁移本地历史资料，也不遵从旧的全局数据库或上传路径兼容覆盖。每会话最多保存20个文件、合计100 MB；达到限制明确拒绝，不自动删除用户文件。原有下载白名单、地址安全、文件大小、解析校验与事务回滚继续生效。

离线问答新增七项指标总览及统一的连续追问识别，并扩充净资产回报率、经营净现金、每股盈利等别称。不能可靠支持的指标仍不生成数值，不将销售额等可能不同口径直接等同于营业收入。

Python 3.12 全量测试466项通过，5项已知PyMuPDF底层SWIG弃用警告。语法编译通过；Benchmark 55/55，输出可解析为JSON。

新增18项用例覆盖真实入库后查询与归因、访客间数据库和文件隔离、评测上下文恢复、非法会话标识、旧全局路径隔离、容量限制、指标总览及连续追问、公共网页操作闭环和显式只读模式。

公共网页交互测试执行检索、下载解析、确认入库、切换企业分析、财报问数和归因树，并开启第二个独立访客验证隔离。此测试使用合成年报和模拟网络响应，写入及查询使用真实SQLite。原有只读界面测试按新权限约定更新；共享主库只读拒绝测试仍保留。

## 真实公网实测

本机通过深交所检索“002594、2024年年度报告”，取得比亚迪年度报告候选，接口返回HTTP 200。随后通过应用安全下载组件取得10,092,140字节官方PDF，在独立临时测试库解析并确认入库，得到3个年度、15项指标。问数返回“比亚迪股份有限公司2024年营业收入为7771.02亿元”。没有使用内置种子数据替代本次解析结果。

## 使用与保留边界

在数据中心选择公开披露接入，检索并下载报告，检查企业、年度、单位与指标后确认入库。若已有内置值且新报告数值不同，需要明确选择覆盖已有指标，否则保留已有值。入库后在财报问数选择该企业，或直接输入其名称、股票代码进行查询。

只有文本而无可靠年度指标的文件，仍可按已有规则明确确认保存为文档，但不能声称已经取得可计算指标。半年报和季报不能写成全年指标。

公共会话刷新、断线或云端重启后不保证恢复；旧临时目录可能在服务生命周期内保留，但不开放给新的访客。公开服务尚未实现账号、跨设备恢复、长期持久存储、自动目录回收和生产级防滥用。长期资料管理应使用本地版或另行配置持久化账户系统。

线上浏览器验收需在托管平台重新部署后单独执行。本地自动测试和公网下载成功不替代云端桌面、移动视口验收。
