# 可靠性修复说明

> 历史版本资料：以下设计、实现范围及验收数字记录当时版本，不代表本次统一资料库修订的运行行为或测试结果。现行资料库、权限、迁移及披露流程见 [统一资料库与公开披露说明](统一资料库与公开披露说明.md)。

本版从星月 UI 正式版复制后独立修改，保留浅色界面与五个业务页面。原版文件及其运行数据未被覆盖。

| 用户问题 | 本版处理 |
| --- | --- |
| 1. PDF解析错位 | 按指标行和年度列提取，排除增长率列；区分无保留和保留意见；未知单位、歧义或异常阻止提交；解析失败不补内置数值。 |
| 2. 种子覆盖导入 | 初始化仅补缺失年度记录；演示、个人、评测分库，个人库为空，已有数值与来源不重写。 |
| 3. 偷换企业/期间 | SQL、分析、降级与检索共享明确条件；未知企业、缺年份及半年/季度请求明确提示。 |
| 4. Excel/CSV | 金额单位换算，区分百分数/比例与Excel格式；逐行企业归属，多工作表；缺主体、重复年度、冲突阻断，含真实XLS/XLSX回归。 |
| 5. 区间与增长 | 区间逐年展开，区分相邻同比、区间增长与CAGR；零/负基数单独处理；多企业多年度逐项回答。 |
| 6. 缺数据评分 | 单指标只比较；综合评分需要完整关键数据，无默认分和无依据倾向；风险显示已检查及缺失规则。 |
| 7. 指标来源 | 每指标保存文件、页码/单元格、原值/单位、导入版本和历史；局部更新不覆盖其他来源，旧版缺少来源标记待复核。 |
| 8. 证据匹配 | 公司与报告年度严格匹配，原因需要直接支持；数字引用核对SQL数值及指标上下文；报告年度独立于比较列年份。 |
| 9. 云端事实 | 显式本地条件优先，保留验证后的云端语义；原答案和数字由程序生成，模型只选择受控解释提示，无效输出回退并记录原因。 |
| 10. 评测与过程 | 扩展原29项基准，加入条件、导入、来源、缺失分析、云端保护和官方年报摘页；显示真实状态、尝试、耗时及失败/降级。 |
| 11. 公共部署 | 默认只读，本地个人库才可写；PDF官方HTTPS精确白名单、公网DNS验证、固定连接IP、逐跳检查，30MB/30秒/最多3跳。 |
| 12. 稳定与效率 | 精确锁定直接依赖，首次安装与日常启动分离；持久目录、在线备份、清单校验、无覆盖恢复/迁移；减少初始化写库并缓存相同报告。 |
| 13. 图表 | 不同单位分图，缺失不填零，去除财务结构饼图，标明年度与单位。 |
| 14. 会话与报告 | 恢复当前服务器会话内历史问答；回答直接下载报告，打开原文页/文件，特殊字符按字面搜索；旧回答的数值/来源/图表/报告保存快照。 |

## 新旧资料衔接

发布包不含运行中的个人数据库、上传资料、缓存或密钥。迁移旧资料请用两系统说明中的显式迁移脚本，只复制到新的个人库，不更改旧库。

旧版已解析错误、单位不明或报告年度标错的记录，仍需对照原件重新复核并导入。代码修复不能凭空恢复旧文件中没有保存的来源，也不意味着旧错误数值已经自动变成正确值。

## 验证范围

实际结果见[最终验收记录](FINAL_ACCEPTANCE.md)。真实材料来自[巨潮资讯比亚迪2024年报](https://static.cninfo.com.cn/finalpage/2025-03-25/1222881496.PDF)，原件校验值与摘页映射在fixture的source.json。

当前结构化库以年度为主；扫描件不自动OCR，复杂表格需人工复核。单文件最多30MB，PDF指标解析前120页并提示扫描范围。固定回归通过不代表所有公司、所有PDF排版或生产并发均已验证。macOS仅核查脚本与说明，未实机运行；真实模型密钥未配置，云端使用受控返回值测试。
