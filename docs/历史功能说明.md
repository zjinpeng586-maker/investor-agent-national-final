# 功能说明

本系统采用“可信数据层 + 分析引擎 + 专业分析模块”的设计。核心财务指标来自本地结构化数据库、用户导入表格或公开披露资料；分析引擎负责问题理解、风险提示、企业对比和报告生成。

## 五个一级页面

- 财报问数：自然语言问数、连续追问、条件澄清、安全 SQL、图表/数据/依据和查询过程。
- 企业分析：合并企业总览、趋势图、风险预警、企业对比和 PDF 报告。
- 研究资料库：展示已接入 PDF、页级本地词法 RAG 索引状态和可核验引用。
- 数据中心：统一承接 CSV、Excel、PDF、在线 PDF、公开披露检索和来源追踪。
- 评测中心：现场运行内置确定性 Benchmark，展示真实样本、通过率、耗时、Case 明细并导出 JSON。

多轮上下文与澄清、安全 Text-to-SQL、页级 RAG、SQL/RAG Hybrid 和本地 Benchmark 均已真实接入。结构化数字以 SQLite SQL 结果为权威来源；RAG 不使用 embedding 或向量数据库，扫描 PDF 不执行 OCR。
