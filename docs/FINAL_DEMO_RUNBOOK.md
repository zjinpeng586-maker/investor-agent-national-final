# 财报智问 V2.0 最终演示运行手册

## 演示前准备

1. 建议使用 Python 3.11，安装依赖后执行 `python -m pip check`。
2. 执行 `python -m pytest -q` 和 `PYTHONPATH=. python scripts/run_benchmark.py`。
3. 运行 `python -m streamlit run app/main.py --server.headless true --server.port 8501`，
   确认 `/_stcore/health` 返回 `ok`。
4. 如需展示真实公司年报引用，提前在“数据中心”接入对应企业和年度的可提取文本 PDF，
   并检查“研究资料库”的 RAG 索引状态。
5. API Key 只在确有需要时通过会话输入或 Cloud secrets 配置，不写入仓库。

## 推荐演示链路

1. 从“财报问数”提问“比亚迪2024年营业收入是多少？”，展示答案、SQL、参数、安全
   校验和真实数据表。
2. 连续追问“那2023年呢？”、“宁德时代呢？”、“净利润呢？”，展示企业、年度和指标
   的上下文继承。
3. 新建会话后直接问“那2023年呢？”，展示系统主动澄清而非沿用旧会话。
4. 提问“比亚迪和宁德时代2024年核心指标对比”，展示双企业 SQL 数据和图表。
5. 如果已接入真实年报，提问文档解释类问题并展示真实文件名、报告年度、PDF 实际页序号
   和原文片段；结构化数字仍以 SQLite SQL 结果为准。
6. 快速展示“企业分析”“研究资料库”“数据中心”。
7. 进入“评测中心”，先说明初始无预置准确率，再点击“运行本地 Benchmark”，展示真实
   样本数、分类结果、耗时、case 明细与 JSON 下载。

## 预期状态与口径

- 五个一级页面都可进入，默认首页为“财报问数”。
- SQL 只读安全链通过后才执行；RAG 使用轻量本地词法排序，不是 embedding 或向量库。
- 页码为 PDF 文件从 1 开始的实际页序号，不宣称是印刷页码。
- Benchmark 是内置确定性回归集，只用于验证当前链路，不代表生产泛化准确率或 SLA。

## 现场 fallback

- **没有真实 PDF**：不要冒充真实年报引用。保留 SQL 演示，并用评测中心本地生成的多页
  测试 PDF 说明 page → chunk → retrieval → citation 链路。
- **公网披露源不可用**：使用内置结构化样例数据，明确公网检索依赖现场网络。
- **云端模型不可用**：切回本地分析模式；多轮、SQL、RAG 和 Benchmark 核心链路不依赖
  云端模型。
- **实例重启导致文件丢失**：重新上传演示 PDF；Cloud 的上传、SQLite 运行时修改和 RAG
  sidecar 不保证持久化。
- **某个 Benchmark case 失败**：直接展开该 case 的 Expected、Actual 与错误，不隐藏失败，
  并继续展示其他 case。
