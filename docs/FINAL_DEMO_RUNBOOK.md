# 可靠性修订版演示与复核手册

> 历史版本资料：以下设计、实现范围及验收数字记录当时版本，不代表本次统一资料库修订的运行行为或测试结果。现行资料库、权限、迁移及披露流程见 [统一资料库与公开披露说明](统一资料库与公开披露说明.md)。

先按 Windows 或 macOS 独立运行说明安装并启动。默认是只读演示库，自己的文件须切到个人库。旧版项目和旧数据无需删除。

## 演示步骤

1. 问“比亚迪2024年营业收入是多少？”，展示真实 SQL、参数、结果、来源；继续问“那2023年呢？”。
2. 新建会话，问尚未接入的“贵州茅台2024年营业收入是多少？”：系统应提示缺企业。如果已导入茅台，请改用确实未接入的企业。
3. 问“比亚迪2024年上半年营业收入是多少？”及“比亚迪2019年有什么风险？”，展示不以全年或最新年替代。
4. 点击“对比两家企业”；只查营收时，不生成综合评分和投资倾向。
5. 数据中心切到个人库并上传文件。检查企业、年份、原值与单位；未确认不能写入，有错误也不能通过勾选绕过。默认只补缺失指标，覆盖须明确选择。
6. 可用 tests/fixtures/byd_2024_key_financials.pdf 演示真实解析。摘页第1–2页对应原年报第10–11页，映射与校验值在相邻 source.json。2024营收、利润和现金流分别为7771.02455、402.54346、1334.53873亿元。该摘件不是完整年报，缺少其他风险与业务章节。
7. 在“指标与来源”打开原 PDF 页或下载原件。2024年报的2023/2022比较数字可入指标库，但不能登记成往年年报。
8. 对仅有部分指标的企业打开企业分析，展示评分与风险规则覆盖不足，而非默认分或低风险。
9. 回答内下载 TXT/PDF；更新数据库后恢复旧会话，旧回答和下载仍保留当时数值与来源，新提问读取新值。
10. 评测中心实际运行，查看每项状态、耗时和错误，下载 JSON。评测隔离运行，不修改个人库。

## 开发验证

用项目虚拟环境的 Python 执行（Windows：.venv/Scripts/python.exe；macOS：.venv/bin/python）：

```text
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m scripts.run_benchmark
```

这里的 python 指项目虚拟环境，不要求系统 Python 安装所有依赖。开发依赖只在运行测试时需要。

内置样例与固定回归不是全市场准确率证明。真实云端调用需要自己的密钥；程序保留事实，仅允许附加受控阅读提示。PDF需人工复核，不能定位或有歧义时不补内置数据。
