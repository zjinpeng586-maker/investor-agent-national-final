# 2026-09-25 归因问答修复与验收

验收对象：擎梦数智｜财报智问，2026-09-25 参赛源码包。基线为 2026-09-24 星月 UI 归因树版。验证范围为本地运行，线上托管不在本记录验收范围内。

## 修复内容

1. 净利润年度解释问题的摘要使用归因树已校验的两年数值，避免上方提示“仅有一个年度”而下方已计算同比。主 SQL 请求年度保持不变，额外比较基期在答案中披露。
2. “增长的主要原因是什么”“怎么解释”等问题优先解析为变化分析，不再误进入指标定义。
3. Planner 与检索共用解释问题识别规则，支持“为何”“归因分析”等问法；纯“净利润是什么”仍为指标定义。
4. Benchmark 命令行的依赖导入警告重定向到标准错误，标准输出保持有效 JSON。
5. “报告中的净利润为什么变化”识别为变化分析；明确的生成报告请求仍保留报告入口。
6. 年度检索排除元数据或 PDF 首页标题标识为半年报、季报的文档，防止跨报告期引用；检索缓存版本升级以重新校验既有文档。

依赖与数据库结构保持一致，现有 UI、导入、企业分析与 PDF 导出实现保持一致。Windows 与 macOS 操作说明统一收录于 README，根目录说明采用参赛作品表述，原双系统文档保留跳转入口。

## 如何查看归因树

运行后进入“财报问数”，新建会话，输入任一句：

- 比亚迪2024年净利润为什么变化？
- 比亚迪2024年净利润增长的主要原因是什么？
- 比亚迪2024年净利润为何增长？
- 比亚迪2024年净利润归因分析

答案摘要下方的“数因融合财务归因”默认展开。当前支持单家企业、年度净利润、单一目标年或连续两个年度；目标年度和上一年度必须有可校验净利润数据。毛利率变化单位为百分点，经营现金流仅作为经营质量辅助线索。

仅问“净利润是多少”、多企业同时归因、季度或半年数据，不属于当前归因树支持范围。没有对应真实年报时，仅展示量化线索并明确报告证据不足。
