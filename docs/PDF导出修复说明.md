# PDF 导出修复说明

> 历史版本资料：本页记录此前 PDF 修复与当时验收结果。统一资料库修订的数据库升级、资料接入及权限规则见 [统一资料库与公开披露说明](统一资料库与公开披露说明.md)。

修订日期：2026-09-24。沿用“财报智问_星月UI归因树版_20260924”目录和安装包。

## 修复内容

- 说明、评分依据、来源与合规提示等表格原先使用不换行的字符串，长内容可能超出单元格或纸张。现统一使用可换行段落，长行可跨页继续显示，表头在续页重复。
- 表格及图形统一按 A4 页面扣除边距和内部留白后的实际宽度布局。评分图保持并排显示，各自按栏宽绘制，避免原始图形宽于容器。
- 中文标点预留字宽，长公司名称、连续英文与链接可换行；不再通过截断段落或仅保留最后四个年度压缩内容。
- 增加页码；排版修订号参与 PDF 缓存键，避免继续返回旧版缓存文件。

## 使用方式

已在本机运行的正式服务完成重启。刷新 http://127.0.0.1:8501/，进入企业分析的“分析报告”，重新点击“下载图文 PDF 报告”。问数回答中的 PDF 下载也使用同一导出器。原先下载到电脑的 PDF 不会自动更新。

在其他电脑更新此安装包后，请关闭旧服务，再按原运行说明启动。无需重新安装依赖或迁移数据库。

## 验证记录

- 45 项相关回归测试通过，包括 11 项 PDF 布局测试：长文字、特殊字符、超长表格行、全部年度与段落保留、图文边界、旧缓存失效等。
- 从实际网页下载比亚迪、宁德时代的财务分析报告，各 8 页，共 16 页。使用不裁剪的文本坐标及矢量边界检查，未发现越界；全部页面经渲染检查。
- 本次验证为 Windows 本地环境；未新增 macOS 实机或云部署测试。
- 机器可读记录见 `validation/pdf-export-verification.json`。归因树验收文档记录的是此前功能交付，最新 PDF 导出变更以本说明为准。
