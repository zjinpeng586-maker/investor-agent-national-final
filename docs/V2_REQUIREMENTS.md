# 财报智问 V2.0 功能范围

> 历史版本资料：以下设计、实现范围及验收数字记录当时版本，不代表本次统一资料库修订的运行行为或测试结果。现行资料库、权限、迁移及披露流程见 [统一资料库与公开披露说明](统一资料库与公开披露说明.md)。

## 一、目标

V2.0 不再延续国赛版“多个独立分析页面并列”的产品形态，而是围绕“自然语言财报问数”重新组织全部已有能力。

核心体验：

**问一个问题 → 得到可核验答案 → 继续追问 → 深入到企业分析、研报依据和数据来源。**

## 二、最终五个一级页面

### 1. 财报问数
默认首页，也是比赛演示主入口。

包含：
- 自然语言输入
- 3–4 个推荐演示问题
- 多轮追问
- 条件补全 / 澄清
- 问数结果
- 图表
- 原始数据
- 来源依据
- 查询过程
- 报告入口
- 进入企业分析入口

### 2. 企业分析
吸收 V1.0 的：
- 企业总览
- 企业对比
- 图表分析
- 风险预警
- 核心指标
- 报告生成

不再把这些能力拆成多个一级页面。

### 3. 研究资料库
面向年报、研报、行业与宏观资料。

包含：
- 资料列表
- 搜索 / 筛选
- 原文阅读
- 文件与页码
- 被哪些回答引用
- 与企业 / 行业的关联

### 4. 数据中心
吸收 V1.0 的：
- 公开披露检索
- CSV / Excel / PDF 接入
- 在线 PDF 接入
- 文件上传
- 解析结果
- 复核
- 来源记录
- 企业数据管理

建议呈现成：
**接入 → 解析 → 复核 → 入库 → 来源追溯**

### 5. 评测中心
比赛验证专用。

包含：
- 查询准确性
- 多轮上下文
- 条件澄清
- 自我纠错
- 响应效率
- 测试题
- 错误案例
- 修正前后对比

所有数字必须来自最终系统真实测试。

| 新增 | 查询过程 | 展示本次问题理解、查询和校验步骤 |
| 新增 | 研究资料库 | 年报 / 研报 / 行业 / 宏观资料 |
| 新增 | 评测中心 | 展示真实测试结果 |
| 新增 | 最近会话 | 支持比赛连续演示 |
| 删除 | 七个横向 Tab | 改为左侧五个一级入口 |
| 删除 | 投资者画像常驻入口 | 不再作为新赛题主线 |
| 删除 | 固定投资建议式结论 | 不在首页长期展示 |
| 删除 | 独立图表页 | 并入问数结果和企业分析 |
| 删除 | 独立报告页 | 作为结果中的生成 / 下载入口 |

| 合并 | 总览 + 对比 + 图表 + 风险 | 企业分析 |
| 合并 | 披露 + 上传 + 来源 | 数据中心 |
| 优化 | 企业 / 期间选择 | 由问题自动识别并同步，人工可修改 |
| 优化 | 问数结果 | 结论、图表、数据、依据集中展示 |

| 保留 | 公开披露检索 | 移入数据中心 |
| 保留 | 文件数据接入 | 移入数据中心 |
| 保留 | 风险预警 | 移入企业分析 |
| 保留 | PDF 报告 | 从结果或企业分析生成 |
| 保留 | 本地 / 云端模式 | 移入设置，不占主界面 |

## 四、登录

比赛版不设置强制登录。

默认：
- 游客可直接进入系统
- 左下角显示游客 / 演示空间
- 后续可增加可选登录

账号系统不是截止日前 P0。

## 五、比赛演示主流程

建议顺序：

1. 进入“财报问数”
2. 基础问数：近三年营业收入
3. 连续追问：改看净利润 / 改年份
4. 企业对比：加入另一家公司
5. 开放分析：解释“增收不增利”等现象
6. 查看依据与查询过程
7. 快速展示数据中心
8. 最后展示评测中心

演示目标：让评委看到的是一条完整任务链，而不是多个互不关联的页面。
