## 实现与验收范围

1. 业务存储固定 `main`，内部 `evaluation` 的路径与写入隔离；公开部署仍拒绝上传、入库和删除。
2. 旧库按自然键合并、逐指标选择优先值、保留来源历史并去重复制附件；事务失败回滚，完成后记录幂等标记。已有 main 修正优先保留。
3. 检索状态区分 success / empty / failed，畸形响应计失败，部分成功不阻断候选。状态在主区域持久展示，新检索清旧状态和预览。
4. 下载解析仅生成预览；入库事务写入企业、指标、来源、报告并前后核验，真实入库才报告成功。仅文档、全部保留、失败和提交后回查异常均独立说明。
5. 入库后重读数据、校正主企业和对比企业选择器、保持当前页面；动态名称/股票代码与相对年份连续问答可用。
6. 历史回答保留原快照；企业或最后报告删除后，历史“进入企业分析”入口禁用，避免跳到其他企业。
7. Schema 版本 3，report_files 新增来源、标题、报告类型、导入标识、哈希、状态与计数字段；旧库幂等升级，严格唯一关系补来源。

## 自动化覆盖

新增统一存储、旧库迁移、旧会话兼容、披露状态、在线入库集成和网页交互测试。使用真实生成的中文 PDF、两个年度的指标、单位与来源核验；网络全部 mock。覆盖原子回滚、文档-only、删除恢复、指标数量、全部企业选择器、新企业多轮问答、公开只读、evaluation 不污染 main，以及上一轮 PDF 排版修复回归。

## 已知边界

- 未执行 macOS 实机和公开云部署验收；线上交易所可用性取决于现场网络，本次接口测试使用 mock。
- 扫描件、复杂表格、身份/单位冲突仍需人工复核；无有效年度指标时只保存文档或阻止入库。
- 原附件缺失或无法唯一匹配时保持待复核，不伪造来源。当前本机迁移未发现缺失附件。
- 会话仍是服务器会话内保存，重启服务不保证恢复；已生成的历史回答继续保留其执行时数据快照。
