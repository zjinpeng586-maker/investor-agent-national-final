投资者智能分析助手

Windows 运行方式：
1. 解压项目压缩包。
2. 双击 run_streamlit.bat。
3. 浏览器打开本地系统页面。

macOS 运行方式：
1. 解压项目压缩包。
2. 打开“终端”，进入项目目录，例如：
   cd ~/Downloads/investor_agent_national_final
3. 推荐使用虚拟环境：
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   streamlit run app/main.py
4. 也可以使用启动脚本：
   chmod +x run_streamlit_mac.sh
   ./run_streamlit_mac.sh

浏览器访问地址通常为：http://localhost:8501

推荐先使用“本地分析模式”进行演示；如需展示云端语言增强能力，可切换到“云端增强模式”，并填写模型服务商与 API Key。
