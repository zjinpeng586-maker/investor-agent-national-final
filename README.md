# 财报智问 V2.0

本项目是基于自然语言交互的上市公司财报智能问数系统。V2.0 以“财报问数”为默认首页，并通过财报问数、企业分析、研究资料库、数据中心、评测中心五个一级入口，承接 V1.0 已有的数据接入、公开披露检索、企业分析、风险识别、企业对比、智能问答、图表和图文报告能力。

## V2.0 页面结构

- **财报问数**：通过自然语言查询财务指标、趋势、风险和企业对比，并查看图表、数据、依据与查询过程。
- **企业分析**：集中展示企业总览、核心指标、趋势图、风险预警、企业对比和报告下载。
- **研究资料库**：展示当前真实接入的年报、公开披露文件和结构化数据来源；页码级引用和 RAG 将在后续阶段接入。
- **数据中心**：统一承接 CSV、Excel、PDF、在线 PDF、公开披露检索、解析入库与来源追踪。
- **评测中心**：如实展示现有检查状态；尚未完成的专项评测不会生成虚构指标。

## 核心能力

- 结构化数据层：内置 10 家新能源产业链企业 2023–2025 年核心财务指标。
- 公开披露检索：支持深交所、上交所公开披露公告检索，定位年度报告 PDF。
- 多路径资料导入：支持 CSV、Excel、PDF 链接和公开披露 PDF 上传。
- 企业总览：展示营业收入、归母净利润、经营现金流、ROE、资产负债率、综合评分等指标。
- 多图表可视化：支持趋势图、柱形图、饼图、雷达图。
- 智能问答：支持财务查询、趋势解释、风险识别、企业对比和报告生成。
- 图文分析报告：生成 7 页结构化 PDF 报告，包含指标卡、趋势图、雷达图、风险关注点和数据来源说明。
- 数据来源追溯：保留导入文件、公开披露链接和指标来源，便于说明结论依据。

## 分析引擎配置

系统提供两种运行模式：

1. **本地分析模式**  
   使用结构化数据层与专业分析规则，能够完成企业画像、风险识别、图表分析、问答和报告生成，不依赖外部模型服务。

2. **云端增强模式**  
   在结构化财务数据和公开来源证据基础上，调用云端模型提升问题理解、表达润色和多角度解释能力。系统支持 DeepSeek、豆包和通义千问。财务数字仍以系统数据为准，大模型不直接生成未经验证的财务数据。

## 运行方式

### 本地运行

#### Windows

Windows 用户可以双击：

```text
run_streamlit.bat
```

也可以在命令行运行：

```bash
pip install -r requirements.txt
streamlit run app/main.py
```

#### macOS

macOS 用户建议使用终端运行。进入项目目录后执行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app/main.py
```

如果已经配置好 Python 环境，也可以直接运行：

```bash
pip3 install -r requirements.txt
python3 -m streamlit run app/main.py
```

项目也提供 macOS 启动脚本：

```bash
chmod +x run_streamlit_mac.sh
./run_streamlit_mac.sh
```

运行后浏览器会打开本地访问地址，通常为：

```text
http://localhost:8501
```

### 局域网展示

Windows 可使用：

```text
run_local_network.bat
```

macOS 可在终端运行：

```bash
streamlit run app/main.py --server.address 0.0.0.0 --server.port 8501
```

## 推荐演示流程

1. 打开系统，选择“本地分析模式”。
2. 展示企业总览：选择比亚迪、宁德时代、上汽集团等内置企业。
3. 展示图表分析：切换趋势图、雷达图。
4. 展示智能问答：询问“比亚迪近三年净利润趋势怎么样”。
5. 展示分析报告：生成并下载图文 PDF 报告。
6. 展示公开披露检索：输入深交所或上交所股票代码，定位公开年报。
7. 根据需要切换“云端增强模式”，展示云端模型对回答表达和报告语言的增强效果。

## 云端模型配置说明

选择“云端增强模式”后，侧边栏会显示模型服务商、模型名称、API Base URL 和 API Key 输入框。API Key 仅在当前运行会话中使用，请勿写入公开仓库。

支持的接口类型：

- DeepSeek
- 豆包
- 通义千问

## 数据口径说明

系统的量化分析以结构化财务指标为基础。PDF 年报用于公开来源记录、资料解析和证据链展示；若 PDF 可形成结构化指标，则自动进入企业总览、图表分析、问答和报告流程。

## 投资研究边界

本系统用于上市公司财务研究、风险识别和投资者辅助分析，不预测短期股价，不提供买入、卖出或保证收益类建议。
