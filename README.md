# 擎梦数智｜财报智问

上市公司财务智能分析平台

通过自然语言查询上市公司财务指标，连接数据接入、连续问答、企业分析、来源追溯与报告下载。界面采用深蓝侧边栏与浅色工作区，保留五个业务页面。结构化数值来自受限只读 SQL；文件证据按公司、年度和页码匹配。缺数据时明确提示，不用其他公司、其他期间或默认评分代替。

工作室品牌为“擎梦数智”，产品名称为“财报智问”。左上角展示本地 Logo、工作室品牌和产品说明；浏览器标题与报告品牌统一为“擎梦数智｜财报智问”。品牌配置集中在 `app/branding.py`，Logo 位于 `app/assets/brand/`。资源缺失时只显示文字品牌，不依赖外部图片地址。

## 数因融合财务归因

在财报问数中输入 **“比亚迪2024年净利润为什么变化？”**，摘要下会显示归因树：净利润年度变化为根节点，营业收入、毛利率为分项线索，经营现金流为经营质量辅助信号。

- 数值通过既有安全 SQL 独立查询相邻两年；毛利率变化用百分点表示，零基数不计算增长率，负基数明确使用绝对值为分母。
- 报告证据须符合同企业、目标年度、对应指标及变化方向；每个节点可展开来源、页码和原文。没有充分证据时明确显示“仅量化线索”。内置 CSV 通常没有原因类年报证据，可在数据中心导入并复核真实年报。
- 默认只为单企业净利润原因类问题展示；“净利润是多少”沿用普通问数。未指定年份时披露选择的最新可用连续两年；指定多于两年或不连续年份时要求明确目标年度。
- 归因结果保存在该回答的会话快照中。它是量化变化与报告解释形成的**分析线索，不是严格因果贡献率**，不会生成“原因贡献占比”。

系统记录披露来源与入库状态，并自动升级已有数据库；依赖版本和 Windows/macOS 启动方式保持不变。完整规则见 [统一资料库与公开披露说明](docs/统一资料库与公开披露说明.md)。

## 本地运行

需要 Python 3.11。完整解压后，按系统阅读独立说明书：

- [Windows 本地运行说明](docs/Windows本地运行说明.md)：首次双击 `install_windows.bat`，以后双击 `run_streamlit.bat`。
- [macOS 本地运行说明](docs/macOS本地运行说明.md)：首次 `bash install_mac.sh`，以后 `bash run_streamlit_mac.sh`。

安装创建独立 `.venv` 并按 `requirements.txt` 的精确直接版本安装。日常启动不执行 pip；只绑定本机 `127.0.0.1:8501`。终端按 Ctrl+C 停止。本地分析不需要模型 API Key。macOS 本次未做实机验证。

## 统一资料库

正常业务固定使用 `main`，数据库位于 `FINANCIAL_DATA_DIR/main/investor_agent.db`。侧栏没有资料库选择。内置企业、上传企业及公开披露导入企业共用企业列表、问答、对比和分析；初始化只补充缺失数据，不覆盖用户已有指标及来源。

启动脚本设置 `FINANCIAL_DEPLOYMENT=local`，本地允许上传、确认入库和删除。公开部署默认 `public`，局域网脚本也固定只读，提示“当前部署为只读模式，无法执行数据导入或删除操作。”评测在内部隔离的 `evaluation` 临时数据库运行，不出现在业务界面，也不读写 `main`。

默认持久目录：Windows `%LOCALAPPDATA%\FinancialReportQA\data`；macOS `~/Library/Application Support/FinancialReportQA/data`。可用 `FINANCIAL_DATA_DIR` 指向稳定磁盘目录，其下的 `main` 保存业务数据。直接运行 Streamlit 且未设置环境变量时，后端默认使用项目 `data/workspaces` 并保持公开只读模式。运行脚本与手动启动应使用相同数据目录。

## 资料与计算

- 数据中心页签为“本地文件接入”“公开披露接入”“数据资产与来源”。公开披露依次执行“检索公开披露”“下载并解析”“数据复核”“确认入库”，检索、解析和入库状态分别显示。
- CSV、XLS、XLSX、可提取文本的 PDF：先解析预览，确认企业、年度、单位和数值，再明确入库；默认不覆盖已有指标。
- 每个指标保留导入版本、来源文件、原始单位以及可取得的页码或单元格位置。旧版未记录的来源标记待复核。
- 年度指标库不把半年或季度映射成全年。未知企业、无目标年度、缺指标都明确提示。
- 同比只用于相邻年度且基数有效的情形；跨年区间增长、年化增长单独表述。缺关键指标不评分、不判断低风险。
- 不同单位分图显示，缺失值不补零；营收、利润等不能构成整体的指标不再生成结构饼图。
- 云端模型负责语言辅助，结构化数字与请求条件仍须程序校验；使用前需在系统设置中配置有效的 API Key。
- 在线 PDF 仅允许精确白名单官方 HTTPS 站点，检查 DNS、固定连接地址、逐跳重定向、大小和耗时。下载失败可手动上传，不绕过网站访问校验。

## 备份与旧版迁移

`scripts/backup_data.py` 使用 SQLite 在线快照并生成附件 SHA-256 清单；`verify_backup.py` 检查备份；`restore_backup.py` 只恢复到不存在的新目录并重定位附件路径。备份时暂停上传、删除和外部文件编辑，以获得整库一致的资料集。

旧双库升级会按自然键合并到 `main`：先处理 `demo`，再处理 `personal`，后者冲突指标优先。数据库关系与原文件路径重新关联；迁移标记防止重复插入，旧目录保留备份。显式指定旧单文件数据库的 `scripts/migrate_legacy_data.py` 则只复制到全新的 `main`，不覆盖已有库。旧版未知单位与来源保持待复核；旧 `reset_db.py` 的隐式删除功能已禁用。具体命令及迁移规则见双系统说明书和 [迁移说明](docs/统一资料库与公开披露说明.md)。

## 页面与边界

财报问数、企业分析、研究资料库、数据中心、评测中心均保留。最近会话保存在当前服务器会话中，可恢复问答和上下文；重启服务后不保证保留。报告从回答内或企业分析页下载。

内置数据覆盖有限企业，固定评测集用于回归验证，不代表全市场覆盖或生产泛化准确率。扫描 PDF/复杂表格需人工核验。当前指标库以年度数据为主。公开部署必须使用持久磁盘与备份；不能依赖云主机临时文件系统保存用户资料。

PDF 长表格自动换行与续页，评分图按可用页宽绘制，导出缓存随排版修订更新。代码更新后，先重启已运行的服务，再重新下载报告。

本系统用于学习研究与信息整理，不预测股价，不提供保证收益或买卖指令。历史实现与验收分别见 [归因功能记录](docs/归因树功能与验收.md)、[数据与计算修复记录](docs/可靠性修复说明.md)、[历史验收记录](docs/FINAL_ACCEPTANCE.md)、[PDF 排版修复记录](docs/PDF导出修复说明.md)；早期设计资料保留于 `docs/V2_*.md`。历史名称和测试数字只描述当时状态，现行运行方式及安全边界以本页、使用说明和两份运行说明为准。
